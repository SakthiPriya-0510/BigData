# Java Hello World

A classic, minimal **Java starter program** that prints "Hello, World!" to the console. This project serves as a basic template for verifying your Java Development Kit (JDK) installation and learning the foundational structure of a Java application.

## 📋 Prerequisites

Before running this program, ensure you have the **Java Development Kit (JDK)** installed on your machine. 

* **Required version:** JDK 8 or higher (JDK 17 or 21 recommended).
* **Verification:** Run `java -version` and `javac -version` in your terminal to confirm installation.

## 🚀 Getting Started

Follow these instructions to clone, compile, and run the program locally.

### 1. Save the Code
Ensure the file is saved exactly as `sample.java`. Java is case-sensitive, and the file name must match the public class name.

### 2. Compile the Program
Open your terminal or command prompt, navigate to the directory containing `sample.java`, and run the Java compiler:

```bash
javac sample.java
```
This action generates a `sample.class` file containing bytecode.

### 3. Run the Program
Execute the compiled bytecode using the Java Virtual Machine (JVM):

```bash
java sample
```

**Expected Output:**
```text
Hello, World!
Added feature
```
